# ⭐ Star Key Escape

A friendly little **room escape game for kids** (ages ~5–9). Three rooms, three
star keys, no reading-heavy puzzles and no way to lose.

**▶ Play: https://ctbot000.github.io/room-escape-game-for-kids/**

## The rooms

1. **Toy Room** — find the secret poster, tap the toy blocks in the right order, grab the golden key.
2. **Snack Kitchen** — count the cookies, punch the number into the fridge magnet lock, take the silver key.
3. **Sunny Garden** — mix two paint pots to make green, pick the matching flower, open the big gate.

## Made for small hands

- Big tap targets, emoji art, no text a 6-year-old can't skip.
- Wrong answers just wiggle and let you try again — nothing is ever lost.
- Works with mouse, touch, and keyboard (Tab + Enter); Esc closes a popup.
- One file, no build step, no dependencies, works offline.

## Run it locally

Open `index.html` in any browser. That's it.

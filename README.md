# ⭐ Star Key Escape

A friendly little **room escape game for kids** (ages ~5–9). Ten rooms, ten star
keys, no reading-heavy puzzles and no way to lose.

**▶ Play: https://ctbot000.github.io/room-escape-game-for-kids/**

## The rooms

| # | Room | What you have to figure out |
|---|------|------------------------------|
| 1 | Toy Room | Tap the blocks in the poster's secret order |
| 2 | Snack Kitchen | Count the cookies, punch the number into the fridge lock |
| 3 | Sunny Garden | Mix two paint pots to make green |
| 4 | Rocket Ship | Put the planets in order, biggest to smallest |
| 5 | Under the Sea | Feed the fish in counting order, 1 → 4 |
| 6 | Dino Cave | Add up the eggs on the cave painting |
| 7 | Candy Shop | Finish the pattern: 🍬 🍭 🍬 🍭 🍬 … ? |
| 8 | Snow Cabin | Find the snowman who isn't like the others |
| 9 | Pirate Ship | Watch the lanterns, then repeat the sequence |
| 10 | Wizard Tower | Light the candles in counting order, 1 → 5 |

Every room follows the same shape, so a child learns it once: a **clue** to look
at, a **puzzle** to solve, and a **door** that opens when the puzzle is done.
Each room also has one extra thing to poke at, just for fun.

## Made for small hands

- Big tap targets, emoji art, no text a 6-year-old can't skip.
- Wrong answers just wiggle and let you try again — nothing is ever lost.
- Progress is saved, so you can close the tab and **Continue** later.
- Works with mouse, touch, and keyboard (Tab + Enter); Esc closes a popup.
- One file, no build step, no dependencies, works offline.

## Run it locally

Open `index.html` in any browser. That's it.
